# 小瞳力视觉训练

儿童视觉发育与弱视恢复家庭辅助训练软件。当前源码对应第 4 次输出版本：`v4`。

## 功能

- 追光小球：训练视觉追踪和注视稳定。
- 拥挤字母：训练精细辨认和抗干扰识别。
- 星星捕手：训练手眼协调和反应。
- 动态高反差背景：缓慢移动色带、漂移棋盘、脉动色点和旋转光环。
- 固定 16:9 训练画面比例。
- 开始、暂停、全屏按钮固定在窗口底部，窗口最大化后无需滚动。
- 本机保存训练记录。

## 医疗提示

本软件仅作为家庭辅助训练工具，不能替代眼科医生或视光师的诊断与治疗方案。遮盖、配镜、红蓝镜、训练时长和训练频率请遵医嘱执行。

## 本地运行

需要安装 Node.js。

```bash
npm install
npm start
```

## 打包 Windows 便携版

```bash
npm install
npm run pack:win
```

打包产物会输出到 `dist/` 目录。

## 项目结构

```text
.
├── index.html      # 应用界面结构
├── styles.css      # 布局、固定底部控制栏、固定画面比例
├── app.js          # 训练逻辑、Canvas 动态背景、计分记录
├── main.js         # Electron 主进程
├── package.json    # 运行和打包配置
└── docs/
    └── CHANGELOG.md
```

## v4 关键修复

- 修复调整窗口大小或最大化后，训练画面把开始/暂停按钮挤到下方的问题。
- 禁用页面整体滚动，按钮固定在软件窗口底部。
- 训练画面固定为 16:9，并在剩余可用空间内自动缩放。
